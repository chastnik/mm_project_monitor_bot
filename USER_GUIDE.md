# Руководство пользователя - Project Monitor Bot

## 🚀 Быстрый старт

### 1. Вход в Jira по Personal Access Token

Перед использованием бота каждый пользователь должен войти в Jira по своему персональному токену (PAT).
Логин и пароль от Jira боту больше не нужны.

**Как получить Personal Access Token (Jira Server / Data Center 8.14+):**
1. Откройте Jira → аватар справа вверху → **Профиль** → **Personal Access Tokens**
   (`<JIRA_URL>/secure/ViewProfile.jspa?selectedTab=com.atlassian.pats.pats-plugin:jira-user-personal-access-tokens`)
2. Нажмите **Create token**, укажите название (например, `Project Monitor Bot`) и при желании срок действия
3. Скопируйте токен — Jira покажет его только один раз
4. Отправьте боту **в личные сообщения**: `login <токен>`

```
login <ваш_токен>
```

⚠️ Отправляйте токен **только в личные сообщения** боту. Если токен случайно попал в общий канал — бот его не сохранит; отзовите такой токен в Jira и создайте новый.

> Если вы пользовались ботом раньше (входили по логину и паролю), после обновления бот пришлет вам уведомление: старое подключение отключено, нужно войти заново по PAT. Ваши подписки сохраняются — проверки возобновятся после входа.

### 2. Проверка подключения

```
test_jira
```

Эта команда проверит, может ли бот подключиться к Jira с вашим токеном.

### 3. Добавление бота в канал

**⚠️ Важно:** Перед подпиской на проекты бот должен быть добавлен в канал!

**Как добавить бота в канал:**
1. Зайти в нужный канал
2. Нажать на название канала → "Управление каналом"
3. Выбрать "Участники" → "Добавить участников"
4. Найти бота по имени (например, `jora` или `standup-bot`)
5. Добавить бота в канал

### 4. Подписка на проект

В канале проекта выполните:
```
subscribe PROJECT_KEY
```

**Пример:**
```
subscribe MYPROJ
```

## 📋 Основные команды

### Вход в Jira
- `login <PAT>` / `войти <PAT>` / `setup_jira <PAT>` - войти по Personal Access Token (только в личных сообщениях)
- `setup_jira` - показать текущее подключение
- `test_jira` - проверить подключение
- `logout` / `выйти` - удалить сохраненный токен

### Просмотр проектов
- `list_projects` - показать все доступные проекты в Jira

### Управление подписками
- `subscribe PROJECT_KEY` - подписаться на мониторинг проекта
- `unsubscribe PROJECT_KEY` - отписаться от проекта
- `list_subscriptions` - показать подписки в текущем канале

### Управление мониторингом
- `run_subscriptions` - запустить проверку подписок текущего канала
- `history [дни]` - история уведомлений
- `status` - статус бота и активные подписки

### Аналитика и графики
- `analytics PROJECT_KEY` / `аналитика PROJECT_KEY` / `графики PROJECT_KEY` - аналитика проекта с графиками (бот присылает текстовый отчет и картинку с графиками в текущий канал)

### Информационные команды
- `help` - полная справка

## 🔍 Что мониторит бот

### 🚨 Превышение трудозатрат
Бот отправляет уведомления когда:
- Фактическое время по задаче превышает плановое время
- Для закрытых задач - только если они закрыты недавно (не раньше вчера)

### ⏰ Просроченные сроки
Бот отправляет уведомления когда:
- Срок выполнения задачи истек (due date <= сегодня)
- Задача еще не закрыта

## 🔐 Безопасность

### Персональные токены
- Каждый пользователь входит по своему Personal Access Token и работает со своими правами в Jira
- Токены хранятся в базе данных бота в зашифрованном виде и маскируются в логах
- Пароли от Jira бот не запрашивает и не хранит

### Рекомендации
- Задавайте токену срок действия и обновляйте его командой `login <новый_токен>`
- Отзывайте токен в Jira, если он больше не нужен или мог быть скомпрометирован (и выполните `logout`)
- Сообщайте администратору о подозрительной активности

## ❓ Частые вопросы

### Q: Нужно ли настраивать подключение к Jira каждый раз?
A: Нет, токен сохраняется. Повторный вход нужен только если токен истек или был отозван — тогда создайте новый и выполните `login <новый_токен>`.

### Q: Могу ли я подписаться на проект, к которому у меня нет доступа?
A: Нет, бот использует ваши права доступа в Jira. Вы можете подписаться только на проекты, которые видите в Jira.

### Q: Что делать, если бот не отправляет уведомления?
A: Проверьте подключение командой `test_jira`. Если есть ошибки — создайте новый токен и выполните `login <новый_токен>`. Проверки по подписке выполняются от имени пользователя, который ее создал: если он не вошел по PAT, переподпишите канал от своего имени.

### Q: Как часто бот проверяет задачи?
A: Бот проверяет все подписанные проекты ежедневно согласно настроенному расписанию.
